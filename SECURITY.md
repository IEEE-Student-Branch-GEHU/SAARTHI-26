# Security Policy

## Supported Versions

We actively maintain the default branch of this repository (`main`). Security updates and patches are applied directly to `main`.

| Version | Supported          |
| ------- | ------------------ |
| main    | Yes                |
| < main  | No                 |

## Reporting a Vulnerability

The IEEE Student Branch GEHU team takes security seriously. If you discover a security vulnerability within this project, please report it responsibly.

### How to Report

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please report vulnerabilities by:
1. Using GitHub's private vulnerability reporting feature:
   - Navigate to the **Security** tab of this repository.
   - Click **Report a vulnerability** to open a private draft advisory.
2. Alternatively, contacting the repository maintainers directly via their official profiles listed in `.github/CODEOWNERS`.

### Information to Include

To help us triage and investigate the issue efficiently, please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue (including proof-of-concept code or HTTP requests if applicable).
- Details regarding affected browsers, operating systems, or environment configurations.
- Any suggested remediation or mitigation strategies.

### Response Timeline

- **Acknowledgment**: Within 48 hours of initial disclosure.
- **Triage & Assessment**: Within 5 business days.
- **Remediation & Patch**: A fix will be developed, tested, and released as promptly as possible based on the severity of the issue.

We request that you keep the issue confidential until we have had reasonable time to evaluate, resolve, and deploy a fix.
